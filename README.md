# HomeOps AI — Marketplace Operations Control Tower

A standalone portfolio prototype for an Ops Project Manager / Marketplace Operations role in student housing.

## What it demonstrates
- AI-assisted student support
- Case classification, confidence and escalation logic
- Marketplace Operations KPIs: resolution, escalation, CSAT, handling time, estimated hours saved
- Knowledge-gap identification
- Product & Tech improvement backlog
- Requirement generation from recurring frontline problems
- Cross-location operating-model standardisation
- Weekly management brief

## Important disclaimer
All operational metrics, cases and location comparisons are synthetic. Public housing-policy examples are based on public help-centre pages and should always be checked against the live platform terms before use in a real case. This is an independent portfolio prototype and is not affiliated with HousingAnywhere, Studapart or Kamernet.

## Run locally
Just open `index.html` in a browser.

## Publish free on Netlify
1. Create a free Netlify account.
2. Drag the folder containing `index.html` into Netlify's manual deploy area.
3. Netlify will create a public URL.
4. Rename the site to something like `homeops-ai` if available.
