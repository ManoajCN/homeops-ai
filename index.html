About HomeOps AI

HomeOps AI is an independent portfolio prototype built by Manoaj Chellan Natarajan to explore how AI-assisted workflows can improve Marketplace Operations in student housing.

The prototype demonstrates how frontline customer interactions can be converted into structured operational cases, intelligent escalation, measurable service feedback and actionable Product & Tech signals.

What this prototype demonstrates

✓ AI-assisted student support
✓ Customer journey and friction classification
✓ Risk, priority and human-escalation logic
✓ Operational queue and team routing
✓ Live CSAT feedback and Ops monitoring
✓ Customer signals translated into Product & Tech requirements
✓ Telephony / IVR routing and escalation simulation
✓ Management-level operational reporting

How the workflow connects

Student question → AI-assisted response → structured case → risk & priority assessment → resolve or escalate → CSAT → operational insight → Product & Tech requirement
Telephony simulation → customer intent → IVR path → queue → priority → escalation / overflow → agent handoff context

Data, sourcing & disclaimer

This is an independent portfolio project and is not affiliated with, endorsed by or connected to any housing marketplace. Baseline operational metrics and demonstration scenarios are synthetic. Live-session interactions are generated during the browser demo and are stored locally for demonstration purposes. Any housing-policy guidance used by the assistant is based only on publicly available information.
